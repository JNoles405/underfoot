# Underfoot

A falling-sand ant farm in one HTML file (`underfoot.html`), played as a Claude artifact:
https://claude.ai/artifact/Nj1KucKdfZLcxEmuFpAXCD
Repo: https://github.com/JNoles405/underfoot. Preview locally with `node serve.js underfoot.html` (port 5291).

## Handover

Read `HANDOVER.md` first. It records the decisions, the traps already paid for and how things
are verified. **It is updated in the same commit as the change it describes**, not at the end of a session.

## Qoder

Qoder project id: `38d09e61-6080-49d6-a753-950db6093af9`.
Qoder is updated alongside `HANDOVER.md`, in the same piece of work as the change:
status, stack, repo and folder via `update_project`, one `add_daily_log` per working session,
and `add_todo` / `complete_todo` as items enter or leave Outstanding.
